# PDF、表格、图片这类文档怎么解析和入库？

::: tip 一句话回答
RAG 的效果上限往往卡在**解析**这一步：PDF 要先做**版面分析**，分清标题、正文、页眉页脚和多栏顺序，扫描件还要 **OCR**；表格不能按行硬切，要转成 Markdown 或"表头 + 行"的文本，并保留表头；图片可以用多模态模型生成**文字描述**再入库，或者直接用多模态 Embedding 检索。每个块都要带上**来源文件、页码、位置**这些元数据，方便过滤和溯源。
:::

## 详细解析

### 为什么解析是瓶颈

PDF 本质是"把字画在页面的某个坐标上"，没有段落和表格的语义。直接抽文本常见的问题：

- 多栏排版被横着读，左右两栏的句子交错拼在一起
- 页眉、页脚、页码混进正文，每一页都重复出现
- 表格变成一串没有分隔的数字，看不出哪个数属于哪一列
- 扫描件抽出来是空的，因为里面只有图片

这些错误在后面的切分、检索、生成环节都补不回来。排查 RAG 效果时，先打开几份解析结果看一眼，往往能发现问题（见 [RAG 效果排查](/ai/rag/10-troubleshooting)）。

### 不同内容的处理方式

| 内容 | 处理方式 | 要点 |
| --- | --- | --- |
| 文字型 PDF | 版面分析识别标题层级、段落、阅读顺序，去掉页眉页脚 | 标题层级用来做按结构切分 |
| 扫描件 | OCR，再做版面分析 | OCR 结果要抽检，数字和专有名词容易认错 |
| 表格 | 转成 Markdown 表格或 HTML；大表按行组切分，每块重复表头 | 合并单元格要展开，否则数字对不上列 |
| 图片、图表 | 多模态模型生成描述（图里有什么、关键数值、结论），描述文本入库 | 原图存对象存储，块里记录图片地址 |
| Word、PPT、网页 | 按自带结构（标题、幻灯片、DOM）解析 | 比 PDF 简单，优先用源格式 |

工具上有开源的版面分析和文档解析库，也有云厂商的文档智能服务，各家对表格和公式的效果差异很大，要用自己的文档实测。

### 表格怎么入库

表格是最容易出问题的地方。几种做法：

- **小表格**：整张表转成 Markdown 作为一个块，前面加上表格标题和所在章节
- **大表格**：按若干行切一块，每块都带表头，否则检索到第 50 行时模型不知道每列是什么
- **行转句子**：把每一行写成"产品 A 的价格是 X，库存是 Y"，适合问单个值的查询
- **数值分析类问题**：比如"哪个季度销售额最高"，检索加生成不擅长，把表格存进数据库，用 Text-to-SQL 查询更可靠（见 [Text-to-SQL 系统设计](/engineering/system-design/08-text-to-sql)）

### 图片的两种路线

1. **转文字**：用多模态模型给图片生成描述，和正文一起做文本 Embedding。好处是检索链路不变，坏处是描述会丢细节，而且描述本身可能出错
2. **多模态向量**：用图文共享向量空间的 Embedding 模型，文本查询直接检索图片。适合以图片为主的场景，比如商品图、设计稿

两种可以并用。检索到图片后，生成阶段可以把原图一起交给多模态模型回答，而不是只看描述。

### 元数据要存什么

每个块至少存：文档 ID、版本、页码、所在章节标题、块类型（正文 / 表格 / 图片）、在页面上的位置。这些字段用于过滤检索、在答案里标出处（见 [引用和溯源](/ai/rag/15-citation)），以及增量更新时定位要删的块（见 [增量更新索引](/ai/rag/12-incremental-index)）。

## 面试官可能追问

::: details 公式和代码块怎么处理？
公式可以识别成 LaTeX 文本保存，代码块要保持原样、不要切断，和 Markdown 的代码块一样作为整体入库。切分时把它们当成不可拆的单元，超长的再按函数或逻辑段落拆。
:::

::: details 解析质量怎么评估？
抽一批有代表性的文档，人工核对解析结果：阅读顺序对不对、表格单元格对不对得上、OCR 错字多不多。更直接的办法是看端到端：用同一个评测集比较不同解析方案的检索召回率和回答正确率。
:::

::: details 为什么不直接把整页截图交给多模态模型？
可以作为补充，比如图表多、排版复杂的页面。但截图不能做关键词检索，Embedding 粒度也粗，一页里有多个主题时检索不准；而且每次回答都带图片，成本和延迟都更高。常见做法是文本块负责检索，命中后再按需附上原页截图。
:::

## 易错点

- 只关注 Embedding 和检索参数，没检查解析结果，问题其实出在第一步
- 大表格切分后丢了表头，检索到的块里只有一串数字
- 图片描述由模型生成，也会出错，重要的图要抽检
- 块里没存页码和位置，事后无法给用户展示出处
