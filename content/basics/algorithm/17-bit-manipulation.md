# 位运算有哪些常用技巧？只出现一次的数字怎么找？

::: tip 一句话回答
位运算直接操作二进制位，常用的是 `&`（与）、`|`（或）、`^`（异或）、`~`（取反）和移位。最常考的技巧：**异或**满足 `a ^ a = 0`、`a ^ 0 = a` 且可交换，把所有数异或一遍，成对的抵消，剩下的就是只出现一次的数，O(n) 时间、O(1) 空间；**`n & (n - 1)`** 消掉最低位的 1，可以数 1 的个数、判断 2 的幂；**位掩码**用一个整数的每一位表示一个开关，适合权限和状态集合。JS 里的位运算会先把数转成 **32 位有符号整数**，超过范围会出错，这是前端特有的坑。
:::

## 详细解析

### 基本运算和常用式子

| 写法 | 含义 |
| --- | --- |
| `x & 1` | 判断奇偶，结果 1 是奇数 |
| `x >> 1` | 除以 2 向下取整（有符号右移） |
| `x \| (1 << k)` | 把第 k 位置 1 |
| `x & ~(1 << k)` | 把第 k 位清 0 |
| `x ^ (1 << k)` | 翻转第 k 位 |
| `(x >> k) & 1` | 读第 k 位 |
| `n & (n - 1)` | 去掉最低位的 1 |
| `n & -n` | 只保留最低位的 1（lowbit） |

`n - 1` 会把 n 最低位的 1 变成 0，它右边的 0 全变成 1，再和 n 相与，正好把这一段清零。`-n` 是 `~n + 1`，和 n 相与只剩最低位的 1。

### 例 1：只出现一次的数字

题目：除了一个数，其他数都出现两次，找出它。**思路**：全部异或，成对的变成 0。

```js
const singleNumber = (nums) => nums.reduce((a, b) => a ^ b, 0)
console.log(singleNumber([4, 1, 2, 1, 2])) // 4
console.log(singleNumber([-3])) // -3
```

**变体：有两个数只出现一次**。全部异或得到 `x = a ^ b`，它不为 0，至少有一位是 1，说明 a 和 b 在这一位不同。用 `x & -x` 取出这一位，按这一位是 0 还是 1 把数组分成两组，a、b 分别落在两组里，每组各自异或。时间 O(n)，空间 O(1)。

```js
function singleNumberIII(nums) {
  const xor = nums.reduce((a, b) => a ^ b, 0)
  const low = xor & -xor // a 和 b 不同的最低位
  let a = 0
  let b = 0
  for (const x of nums) {
    if (x & low) a ^= x
    else b ^= x
  }
  return [a, b]
}
console.log(singleNumberIII([1, 2, 1, 3, 2, 5])) // [3, 5]（顺序不固定）
```

### 例 2：数 1 的个数、判断 2 的幂

每次 `n &= n - 1` 消掉一个 1，循环次数等于 1 的个数，比逐位检查 32 次快。2 的幂的二进制只有一个 1，所以 `n & (n - 1)` 为 0。

```js
function hammingWeight(n) {
  let count = 0
  while (n !== 0) { // 用 !== 0 而不是 > 0，负数也能正确结束
    n &= n - 1
    count++
  }
  return count
}
const isPowerOfTwo = (n) => n > 0 && (n & (n - 1)) === 0
console.log(hammingWeight(11), hammingWeight(-1)) // 3 32
console.log(isPowerOfTwo(16), isPowerOfTwo(0), isPowerOfTwo(6)) // true false false
```

### 位掩码：权限和状态

每一位代表一个开关，一个整数就能存一组布尔值，判断和组合都是一次位运算：

```js
const READ = 1 << 0 // 0b001
const WRITE = 1 << 1 // 0b010
const DELETE = 1 << 2 // 0b100

let perm = READ | WRITE // 授予读写
const canWrite = (perm & WRITE) !== 0 // 检查
perm &= ~WRITE // 收回写权限
console.log(canWrite, perm) // true 1
```

Linux 文件权限 rwx、React 内部的 flags 都是这种用法。算法里常用 n 位掩码表示一个集合，从 0 到 `2^n - 1` 枚举就是枚举所有子集，回溯写法见[回溯算法](/basics/algorithm/11-backtracking)；状态压缩 DP 也用掩码做状态。

### JS 位运算的坑

JS 的数是 64 位浮点数，但 `& | ^ ~ << >>` 会先转成 32 位有符号整数再运算，`>>>` 转成 32 位无符号整数：

```js
console.log(1 << 31) // -2147483648，第 31 位是符号位
console.log((1 << 31) >>> 0) // 2147483648，>>> 0 转成无符号
console.log(2 ** 32 | 0) // 0，高位被截掉
console.log(0.7 | 0, -5 >> 1) // 0 -3，>> 是向下取整，不是向零取整
```

- 掩码超过 31 位就不能用普通数，改用 `BigInt`（`1n << 40n`），或者拆成多个整数
- `x | 0` 和 `~~x` 常被用来取整，但只对 32 位范围内的数正确，时间戳这类大数会被截断
- 时间复杂度分析里，位运算按 O(1) 计

## 面试官可能追问

::: details 其他数都出现三次，只有一个数出现一次怎么办？
异或抵消不了三次。按位统计：对 32 个位分别数所有数在这一位上 1 的个数，对 3 取余，余数就是目标数在这一位的值。时间 O(32n)，空间 O(1)。也可以用两个变量模拟三进制计数的状态机，面试能讲清按位统计就够。
:::

::: details 不用加号怎么实现两数相加？
异或是不进位加法，`(a & b) << 1` 是进位，循环把进位加回去直到进位为 0。在 JS 里结果受 32 位限制，负数和溢出要额外注意。
:::

::: details 交换两个变量能用异或吗？
可以写 `a ^= b; b ^= a; a ^= b`，但如果 a 和 b 是同一个内存位置（比如数组同一个下标），结果会变成 0。可读性也差，实际写代码用解构 `[a, b] = [b, a]`。
:::

## 易错点

- 判断位时写成 `x & 1 << k === 0`：`===` 优先级高于 `&`，要加括号 `(x & (1 << k)) === 0`
- 数 1 的个数用 `while (n > 0)`，负数直接跳过循环
- 在 JS 里对超过 32 位的数做位运算，结果被悄悄截断
- 把 `>>` 当成除以 2 向零取整：负数时是向下取整
