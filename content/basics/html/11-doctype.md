# DOCTYPE 有什么作用？标准模式和怪异模式有什么区别？

::: tip 一句话回答
DOCTYPE 告诉浏览器用哪种**渲染模式**解析页面。有正确的 DOCTYPE 就走**标准模式**，按 CSS 规范渲染；缺失或写成老旧形式就进入**怪异模式**（quirks mode），模拟早期浏览器的非标准行为，比如行高、百分比高度、表格样式的计算方式不同。老 IE 的怪异模式还会把盒模型按 border-box 计算，这是最常被问到的一点。HTML5 只需要写 `<!DOCTYPE html>`，放在文档第一行。用 `document.compatMode` 可以检查当前模式。
:::

## 详细解析

### 为什么会有两种模式

早期浏览器各自实现了一套不符合规范的渲染规则，大量老网页依赖这些行为。后来浏览器开始遵循 CSS 规范，但又不能让老页面全部错乱，于是用 DOCTYPE 作为开关：新页面声明 DOCTYPE，表示"按标准来"；没声明的老页面，继续用兼容老行为的怪异模式。

DOCTYPE 不是 HTML 标签，也不会去下载什么文件，它只是一个触发渲染模式的声明。

### 三种模式

| 模式 | 触发方式 | `document.compatMode` |
| --- | --- | --- |
| 标准模式 | `<!DOCTYPE html>` | `"CSS1Compat"` |
| 准标准模式 | 某些带过渡型标识的老 DOCTYPE | `"CSS1Compat"` |
| 怪异模式 | 没有 DOCTYPE，或某些很老的 DOCTYPE | `"BackCompat"` |

准标准模式和标准模式几乎一样，只在表格单元格里的图片行高上沿用了老行为。现在写新页面，只要记住 `<!DOCTYPE html>` 就够了。

另外，DOCTYPE 前面出现注释以外的内容，或者 DOCTYPE 不在最前面，都可能让浏览器进入怪异模式。

### 怪异模式下常见的差异

- **盒模型**：老 IE 的怪异模式下 `width` 包含 padding 和 border，相当于整页默认 `box-sizing: border-box`，"IE 盒模型"的说法就来自这里。现代浏览器的怪异模式已经不对普通元素这样做，只在表格单元格的高度上保留了类似的计算。盒模型的细节见 [盒模型](/basics/css/01-box-model)
- **行高和行内图片的间隙**：标准模式下，块级容器里的行内图片底部会留出几像素空白，因为图片按基线对齐，行框里要给文字下伸部分留空间。怪异模式下块容器在一些情况下不受 `line-height` 撑高，常常看不到这个空白
- **其他**：部分属性的颜色值可以省略 `#`、部分属性的长度可以省略单位（如 `width: 100`），`html` 和 `body` 在一定条件下会撑满视口高度
- **百分比高度**：怪异模式下，父元素高度为 auto 时百分比高度会继续向上找祖先来计算，比标准模式宽松，标准模式下父元素没有明确高度时百分比高度不生效
- **表格**：怪异模式下表格默认不继承外部的字体大小、字重等部分文字样式

同一份 CSS 在两种模式下表现不同，这就是"本地好好的，换个页面就错位"的一类原因。

## 代码示例

```html
<!DOCTYPE html>
<html lang="zh-CN">
  <head>
    <meta charset="UTF-8" />
    <title>示例</title>
  </head>
  <body></body>
</html>
```

```js
// 在控制台检查当前页面的渲染模式
console.log(document.compatMode) // "CSS1Compat" 是标准模式，"BackCompat" 是怪异模式
```

## 面试官可能追问

::: details 为什么 HTML5 的 DOCTYPE 这么短？
以前的 HTML 4 基于 SGML，DOCTYPE 要引用 DTD 文件来定义文档结构。HTML5 不再基于 SGML，不需要 DTD，DOCTYPE 只剩下"触发标准模式"这一个作用，所以取能触发标准模式的最短写法。它不区分大小写。
:::

::: details 怎么去掉标准模式下图片底部的空白？
原因是图片默认按基线对齐。可以把图片设为 `display: block`，或者 `vertical-align: middle` 或 `bottom`，也可以把父元素的 `font-size` 或 `line-height` 设为 0。
:::

::: details iframe 里的页面用什么模式？
由 iframe 加载的那个文档自己的 DOCTYPE 决定，和父页面无关。嵌入老页面时，iframe 里可能是怪异模式，样式表现和父页面不一样。
:::

## 易错点

- 以为 DOCTYPE 是 HTML 标签或者要下载 DTD。在 HTML5 里它只是一个模式开关
- 把 DOCTYPE 写在注释、空白以外的内容后面，或者服务端模板在前面输出了其他内容，导致意外进入怪异模式
- 以为现代浏览器的怪异模式还会把所有元素按 border-box 计算。那是老 IE 的行为，现在的差异主要在行高、百分比高度和表格上
