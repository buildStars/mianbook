# 人工标注怎么保证一致性？

::: tip 一句话回答
一致性靠**流程**保证：写清楚**标注指南**，每个等级配正反例；正式标注前**试标和校准**，大家标同一批样本、讨论分歧、修订指南；正式标注时抽一部分样本**多人重复标注**，用 **Cohen's Kappa** 这类指标衡量一致性，有分歧的交给仲裁。标注员之间一致性低，通常说明标准本身没说清楚，而不只是人的问题。
:::

## 详细解析

### 为什么一致性重要

人工标注是评测的基准，也常用来校准 LLM 评委（见 [LLM-as-a-Judge](/engineering/eval/02-llm-as-judge)）。如果两个人对同一个回答一个打 4 分一个打 2 分，那这份标注的噪声比模型版本之间的差异还大，基于它做的决策就不可靠。

### 标注指南

指南要让一个新人看完就能标，至少包括：

- **任务定义**：评什么，比如"回答是否正确且完整地回答了用户问题"，不评语气和长度
- **等级定义**：每一档的具体条件。"基本正确"太模糊，写成"核心结论正确，缺少次要信息，没有错误信息"
- **正反例**：每一档配几个真实例子，尤其是处在两档边界上的
- **特殊情况**：问题本身有歧义、参考答案有误、回答部分拒答时怎么标

能用二元判断或少数几档就不用 10 分制。档位越多，分歧越大。复杂的质量判断可以拆成多个独立的二元问题，比如"是否事实正确""是否回答了问题""是否有不安全内容"。

### 试标和校准

1. 选一批有代表性的样本，所有标注员独立标注
2. 计算一致性，把分歧大的样本拿出来讨论
3. 讨论结论写回指南，补充新的例子
4. 重复一两轮，一致性达到团队认可的水平后再正式开始

这一步最容易被省略，但它决定了后面数据的质量。

### 一致性指标

直接算两个人标得一样的比例（一致率）会高估一致性：如果 90% 的样本都是"正确"，两个人随便标也能有很高的一致率。Cohen's Kappa 扣除了偶然一致的部分：

```text
κ = (po − pe) / (1 − pe)
po：实际一致的比例
pe：按两人各自的标签分布，随机标注时预期的一致比例
```

κ = 1 表示完全一致，0 表示和随机差不多。两人以上可以用 Fleiss' Kappa 或 Krippendorff's Alpha；有序的打分可以用加权 Kappa，标 4 和 5 的分歧比标 1 和 5 的小。

### 正式标注中的质量控制

- **重叠标注**：每批抽一部分样本让多人标，持续计算一致性，发现下降及时校准
- **仲裁**：分歧样本交给资深标注员或领域专家定最终标签，并记录分歧原因
- **埋入已知答案**：混入标准答案已确定的样本，检查每个标注员的准确率
- **盲标**：不告诉标注员回答来自哪个模型或版本，避免先入为主
- **关注疲劳**：长时间标注质量会下降，控制单次时长，监控每人的标注速度和分布

## 代码示例

```js
// 两名标注员的 Cohen's Kappa
function cohenKappa(a, b) {
  const n = a.length
  const labels = [...new Set([...a, ...b])]
  const po = a.filter((x, i) => x === b[i]).length / n
  const pe = labels.reduce((sum, l) => {
    const pa = a.filter((x) => x === l).length / n
    const pb = b.filter((x) => x === l).length / n
    return sum + pa * pb
  }, 0)
  return pe === 1 ? 1 : (po - pe) / (1 - pe)
}

const a = ['对', '对', '对', '错', '对', '错', '对', '对', '对', '对']
const b = ['对', '对', '错', '错', '对', '对', '对', '对', '对', '对']
console.log(cohenKappa(a, b).toFixed(3)) // 一致率 0.8，Kappa 只有 0.375
```

## 面试官可能追问

::: details Kappa 多少算合格？
常见的参考分档把 0.6 以上看作较好的一致性，0.8 以上看作很好，但这些分档是经验性的，不同任务要求不同。主观性强的任务（比如评价写作风格）一致性天然会低一些。更重要的是看趋势和分歧集中在哪里，用来改进指南。
:::

::: details 一致性始终很低怎么办？
先看分歧集中在哪些样本：如果集中在某类边界情况，补充指南和例子；如果是任务本身太主观，把评分拆成更具体的二元问题，或者改成两个回答比较哪个更好，比较通常比绝对打分更容易一致。
:::

::: details 能用 LLM 代替人工标注吗？
可以用来做初标或扩大规模，但要先拿一批人工标注的数据校准，计算 LLM 和人的一致性，达到人与人之间的水平才放心使用。之后也要定期抽样复核，因为评委模型和 Prompt 变化都会影响结果。
:::

## 易错点

- 只算一致率不算 Kappa，标签分布不均衡时一致性被高估
- 跳过试标校准，直接开始大规模标注
- 档位定义模糊，或者分档过多
- 分歧样本用多数投票直接定，不分析原因，也不更新指南
